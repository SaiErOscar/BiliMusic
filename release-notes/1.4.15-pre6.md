# BiliMusic v1.4.15-pre6

## 本地音乐现在能播放了

上一个预览版只能扫描和浏览，这一版接上了播放。

- **直接点就播**：本地曲目和 B 站曲目用同一套播放器，进度条、倍速、循环、随机都一样。
- **均衡器照常工作**：十段均衡器对本地音乐同样生效。
- **音频可视化照常工作**：频谱动画不会因为换成本地文件而失效。
- **拖动进度条可靠**：长音频跳转是真正的定位，不是从头重新加载。

## 文件丢了会怎样

- 列表里那一首会标上「已丢失」。
- 点它会提示「文件已丢失，可能被移动或删除」，然后停下——**不会自动跳到下一首**，免得你不知道刚才发生了什么。
- 想清理掉这些条目，用「清理失效」按钮，需要你自己点。

## M3U 里的本地音乐

上一版从 M3U 导入时，本地文件路径的条目会保留但播不了。现在这类条目会被识别成本地曲目，直接能播：

```
file:///C:/Music/稻香.mp3
C:\Music\稻香.mp3
/home/user/Music/稻香.mp3
```

三种写法都认。如果同一个文件既在「本地音乐」页扫到、又从 M3U 导入过，会是同一条曲目，不会重复。

## 说明

- 不新增依赖。
- 扫描与播放都不修改任何音频文件，只读取。

## 已知限制

- 本地曲目没有封面（音频文件里一般不存封面图，这一版没做提取）。
- 本地曲目不计入播放统计与听歌画像。
