## v1.2.0 — 安全加固与性能优化

**发布日期：2026-08-04**

### 安全修复

- **远程调试端口条件化**：生产环境不再暴露 Chrome DevTools Protocol 端口
- **托盘窗口安全隔离**：关闭 `nodeIntegration`，启用 `contextIsolation`，新增专用 `tray-preload.cjs`
- **下载文件名安全过滤**：`../` `\` `/` `:` `*` `?` `"` `<` `>` `|` 等危险字符替换为 `_`

### 性能优化

- **播放进度持久化防抖**：移除每秒 4 次的 `timeupdate` 依赖，改为 5 秒间隔低频写入
- **音频 URL 内存缓存**：30 分钟 TTL，命中时跳过两次 API 请求
- **音频加载失败自动重试**：403 时清除缓存并重试一次

### 功能改进

- **播放音质设置生效**：标准/高品质/无损三档，映射到不同音频流
- **ESLint 配置**：`@typescript-eslint` + `react-hooks`，新增 `npm run lint`
- **TypeScript 零错误**：修复全部 4 个原有类型错误
- **死代码清理**：净减 244 行（移除 9 个未使用 IPC handler、`usePlayer.ts` 等）

## v1.2.6 — 视频下载修复与控件对齐

**发布日期：2026-08-05**

### 修复

- **视频下载失败（ffmpeg 路径解析）**：ESM 中 `require('ffmpeg-static')` 不可用
  - 通过 `createRequire(import.meta.url)` 桥接
  - 三级 fallback 策略：ffmpeg-static → 常见路径检查 → 系统 PATH
- **视频下载内存峰值**：`downloadStream()` 从返回 `Buffer` 改为流式写入文件
- **B站 CDN 反爬拦截**：所有 HTTP 请求添加 `User-Agent` 头

- **播放控件不对称**：循环/随机按钮从中间控制区移到右侧
  - 中间变为对称三按钮：上一首 | 播放 | 下一首
  - CSS grid 列宽从 `54px 78px 54px 46px` 改为 `46px 70px 46px`
