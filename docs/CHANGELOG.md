## v1.2.19 — 收藏夹加载修复与同步频率调整

**发布日期：2026-08-06**

### 修复

- **收藏夹内容加载失败（返回 HTML 而非 JSON）**：根因是 B站收藏夹内容接口 `/x/v3/fav/resource/list` 在请求未携带完整登录 Cookie 时会被风控返回 **HTTP 412 + HTML 验证页**（而非 JSON）。原实现走渲染层 `biliFetch`，无法携带完整 Cookie，`resp.json()` 解析 HTML 触发 `Unexpected token '<' ...` 错误，且错误信息直接暴露到 UI、误判「收藏夹为空」
- 现改为：收藏夹内容请求改走**主进程 `net.fetch`**（自动带 Cookie + Referer + UA，与收藏/取消收藏一致）；新增通用 `bili:fetchBiliJson` handler，先读取文本并校验 content-type / HTTP 状态，返回非 JSON 或风控时抛出友好错误（提示重新登录），不再暴露原始解析错误
- UI 层新增 `loadError` 状态：加载失败时显示「收藏夹加载失败」+ 友好错误信息，而非误判为「收藏夹为空」

### 优化

- **收藏夹自动同步频率**：由每 10 秒调整为每 30 秒一次（打开页面 / 切换收藏夹仍即时触发）

## v1.2.18 — 收藏夹修复、封面渲染与音量留白调整

**发布日期：2026-08-06**

### 修复

- **取消收藏失败**：根因有二——① B站 deal 接口的 `rid` 需为 aid，但部分曲目 aid 为 0（音乐中心/推荐来源）导致无法取消；② 主进程 deal 请求缺失 B站 web 端风控字段（`eab_x`/`ga`/`gaia_source`）被风控拦截。现统一修复：`rid` 支持 aid 或 bvid 兜底（B站 deal 接口两者均可），收藏弹窗与收藏夹页移除按钮均可用 bvid 兜底；主进程补充风控字段
- **收藏夹封面不显示**：根因是 B站收藏夹内容接口 `/x/v3/fav/resource/list` 返回的封面字段名为 `cover`（而非 `pic`），且视频 id 为 `id`（即 avid）而非独立 `aid` 字段。现修正 `FavoriteItem` 接口与映射，封面用 `cover`、aid 用 `id` 兜底，收藏夹页每首歌正常渲染封面
- **收藏弹窗默认勾选遍历不全**：判断曲目已收藏在哪些收藏夹时，由「每个收藏夹仅取前 50 个」改为「遍历收藏夹全部内容（自动翻页）」，确保超过单页上限也能匹配并默认勾选

### 优化

- **音量控件留白**：竖向音量滑块上下留白由约 7px 调至 10px
- **下载页打开链接**：下载记录行「打开原链接」由 Electron 内部新窗口改为系统默认浏览器外部打开

## v1.2.13 — 批量下载进阶与收藏修复

**发布日期：2026-08-05**

### 优化

- **属性与歌词选项分离**：单曲下载与批量下载中，「修改文件属性（写入歌手）」与「同时下载歌词(.lrc)」拆分为两个独立开关，可分别勾选

  - 中间变为对称三按钮：上一首 | 播放 | 下一首
